# Glücksrad-Abstimmung

Diese einfache Web-App hilft bei einer Abstimmung mit mehreren Antwortmöglichkeiten.

## So verwendest du die App

1. Entpacke den Ordner.
2. Öffne den Ordner in Visual Studio Code.
3. Öffne die Datei index.html.
4. Klicke auf "Öffnen mit Live Server" oder öffne die Datei im Browser.

## Funktionen

- Frage und Antwortmöglichkeiten eingeben
- Stimmen abgeben
- Ergebnis anzeigen
- Glücksrad drehen
- Gewinner anzeigen
