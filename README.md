# Glücksrad-Abstimmung

Diese einfache Web-App hilft bei einer Abstimmung mit mehreren Antwortmöglichkeiten.

## So verwendest du die App

1. Entpacke den Ordner.
2. Öffne den Ordner in Visual Studio Code.
3. Öffne die Datei index.html.
4. Klicke auf "Öffnen mit Live Server" oder öffne die Datei im Browser.

## Funktionen

- Frage und Antwortmöglichkeiten eingeben
- Stimmen abgeben
- Ergebnis anzeigen
- Glücksrad drehen
- Gewinner anzeigen
- Raum-Modus ohne Datenbank
- Online-Modus mit Supabase

## Supabase einfach einrichten

### 1. Supabase-Konto erstellen

1. Gehe auf https://supabase.com
2. Klicke auf "Start your project"
3. Erstelle ein kostenloses Konto
4. Melde dich an

### 2. Neues Projekt erstellen

1. Klicke in Supabase auf "New project"
2. Wähle einen Projektnamen
3. Wähle eine starke Passwort-Option für die Datenbank
4. Klicke auf "Create new project"

### 3. SQL-Code einfügen

1. Öffne in Supabase den Bereich "SQL Editor"
2. Klicke auf "New query"
3. Füge diesen Code ein:

```sql
create table if not exists polls (
  id bigint generated by default as identity primary key,
  created_at timestamp with time zone default now(),
  question text not null,
  options text[] not null,
  room_code text not null unique,
  is_closed boolean default false
);

create table if not exists votes (
  id bigint generated by default as identity primary key,
  created_at timestamp with time zone default now(),
  poll_id bigint references polls (id) on delete cascade,
  option text not null,
  voter_name text not null,
  browser_key text not null
);

alter table polls enable row level security;
alter table votes enable row level security;

create policy "Allow public inserts" on polls
for insert to public using (true) with check (true);

create policy "Allow public selects" on polls
for select to public using (true);

create policy "Allow public updates" on polls
for update to public using (true) with check (true);

create policy "Allow public inserts on votes" on votes
for insert to public using (true) with check (true);

create policy "Allow public selects on votes" on votes
for select to public using (true);
